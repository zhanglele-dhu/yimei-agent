# M22 资料检索与写作

分类目录位于 `outputs/studio/knowledge_base/m22/README.md`，12个分类文件夹位于同目录的 `分类资料/`。

来源卡以厂商资料、论文、专家共识、监管记录、教材患教、试验注册、专业问答分别记录。每条有稳定编号、原始链接、阅读范围与适用范围。论文卡保留DOI/PMID、研究设计、人群与样本信息，正文为中文概括；原始摘要和检索式保存在 discovery.json。摘要级卡经过第二次模型调用对照原摘要，修正记录写入corrections；这项核对不等于全文评审。

## 已接入的调用链

`sources_for → kb_source → evidence.search_library → 主题路由与词法检索 → KB及逐条M22来源 → 分析/大纲/草稿模型`

1. 按用户需求或已识别的创作目标选择主题。
2. 设备定义和滤片问题优先取厂商、共识、教材等对应资料。
3. 研究结论保留人群、模块和联合干预范围，不将通用IPL研究自动写成M22专属优势。
4. 皮肤科普检索排除独立眼科应用；论坛和医生问答在讨论类需求中提供问题和观点。
5. 生成文案直接解释知识，逐条来源编号留在source_ids和导出包；只有阻碍当前内容的具体缺口进入pending。
6. 不要求无关的门店资料：基础原理科普不需要门店报价、病例或医生身份。涉及某家门店配置时才使用SHOP资料。

本地索引用512维字符二元组哈希向量及词法重排，不需要额外的嵌入模型密钥。它是离线词法检索，意图识别继续由现有文字模型完成。

## 手动更新

```powershell
.venv-studio/Scripts/python.exe -X utf8 -m studio.collect_m22 --discover --summarize --audit --as-of 2026-10-24
.venv-studio/Scripts/python.exe -X utf8 -m studio.evidence
```

更新时改为实际检索日期。采集脚本可复用已完成的资料卡，失败的批次记入报告，不会无限重试。索引采用版本目录及原子清单切换；服务按清单版本更新缓存。原有corpus和store保留，新M22任务优先使用新的分类库。

范围记录包括公开页面和可获取的论文摘要；付费全文、登录后论坛及完整中国注册证附件另列在覆盖缺口中，未标记为已读。

# 小红书成品模板

当前默认生成方式已改为 [Skill 与模型设计流程](MODEL_CARD_PIPELINE.md)。本文仅描述用户明确选择 `template` 模式时使用的固定程序版式。

模板版本：`xhs-editorial-v1`。入口为 `rendering.render`，实现为 `card_layout.render_card`。

参考本机 `xhs-note-creator/SKILL.md` 的封面与正文分离、短段落、固定画布、主题和分页原则，以及 `assets/themes/professional.css` 的标题层级、段落间距、信息块样式。规则已落实在项目代码中；运行工作台不需要调用 Codex、读取用户目录中的 skill 或另外安装浏览器。未接入 skill 的发布脚本。

- 文字卡默认 1080×1440，清爽杂志、奶油卡片、撞色重点三套配色共用内容层级。
- 第一页使用更醒目的标题；正文按原有换行分块，显式箭头流程改为步骤，超过四步使用双列排列。不推断或改写医学事实。
- 实拍照片居中置于独立相片区，不缩放、不裁切、不覆盖；尺寸较大时扩大画布，保持 3:4。`photo_offset_x` 和 `photo_offset_y` 记录像素原点。
- 标题、正文先测量再绘制；容纳不下时提示精简，禁止截断文字或遮挡页脚。过密内容可能使用较小字号，建议每页 80–180 字。
- 独立段落中以“实拍建议：”“拍摄建议：”“拍摄提示：”“配图建议：”“排版说明：”“制作说明：”开头的制作提示不进入成品；该提示后的同段续行一并排除，遇空行结束。编辑区实时列出被排除的内容。
- 原始编辑文字保持原样；成品元数据分别记录 `public_text`、`production_notes` 和 `layout_version`，来源记录与运行日志可追溯。
- 新草稿提示词明确要求拍摄指导留在大纲 `instruction` 中，发布文字放在 `pages.text` 中。
- 旧图片保持不变。核对文字并重新点击“确认并生成本页图片”后才生成新版；编辑区显示旧版提醒。聊天卡继续使用原有对话布局。

验证：`python -m unittest test.test_card_layout`，另运行 `test_studio` 中照片像素、默认主题、AI 底图降级和对话卡等接口用例。
